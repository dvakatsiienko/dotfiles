For the last few days, I've been using background agents to do most of my work, and I've been extremely impressed by them, but also kind of concerned that most companies are not in the position to take advantage of them. I've been using Curser's Slack integration to spin up cursor agents, doing my prompting within this nice UI here, which then spins up a background agent in its own remote environment to complete the work and actually do all of the coding, etc. Crucially, it then creates a PR. And here's the important bit, which is that on my work monor repo, I have a really welltuned CI here which runs in about a minute and does type checking, does tests, does linting. As you can see from the output, I'm using Turbo Repo, running tests in all of the packages and apps in my big monor repo. And when it goes wrong, it provides really detailed feedback to the AI. Now, I'm a CI nerd. I used to work at Versel as the Devril for Turbo Repo. I can already see a massive opportunity for plumbing nerds like me to improve their repos ready for background agents. Because I'm confident in my CI, I can look at the code the agent has produced and go, "Yeah, that seems pretty good. Let's merge it and test it locally." And having a laser focus on TypeScript rules, on ESLint rules, on unit tests as well means I can lock down the AI to exactly what I want and massively improve the output of the code I get from the AI.
