# vibe — fleet-global terminology

Adopted words. Recognize them from Dima, use them back sparingly.

- **slay** = push (git push). «go slay» → push it. Adopted 2026-08-19.
- **freebie** = a ticket/action executable without Dima's approval (pre-approved or approval-free by contract). «do the freebies» → run them unprompted. Adopted 2026-08-19.
