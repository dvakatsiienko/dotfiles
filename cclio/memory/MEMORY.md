# cclio memory index

barrel file. one line per memory, pointing at a leaf in this dir. content lives in the
leaf, never here. keep each line short enough that the whole index reads cheap at boot.

format:
```
- [slug](slug.md) — one line, what it decides, in imperative present tense
```

rules:
- add a pointer only when the memory earns a leaf. otherwise fold it into an existing one.
- a leaf is a single decision or protocol, not a topic dump.
- stale pointer = delete both lines and file. no tombstones.
- emoji prefix is allowed as a salience marker (📌 ⏰ 🧭), never as decoration.
