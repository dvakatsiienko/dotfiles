# restate a batch before acting on it

**When Dima's message carries several separate items, open the reply with a short numbered list of
what was parsed out of it.** Then act. He corrects a misread before it becomes work.

## what this replaces

The obsidian flowlog carried a request for a **prompt pre-processor** — a codified sanity pass over
batch dumps. Grilled and settled: no framework, no new syntax. The restate does the same job at
roughly zero cost.

## why no syntax

His format is already parseable and it is his own, unprompted:

- `←` means «my comment on the line above». Consistent, and it works.
- `note:` marks an aside.
- `just thoughts` marks an observation with no action wanted. He wrote it unprompted and it worked.

What is genuinely missing is **do-this vs think-about-this**, and **order**. Both could be fixed with
markers — but a marker set is a thing to remember while tired, which is exactly when the batches
arrive. So the burden goes on the reader, not the writer.

## the shape

    parsed: 1. rename the mcp verbs · 2. seed the design-system milestones ·
            3. answer the naming question · 4. (observation, no action) ctx cost

Short. One line per item. Mark the ones you read as observation-only, because those are the ones a
wrong read turns into unwanted work.
